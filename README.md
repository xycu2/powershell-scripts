# PowerShell Scripts

A collection of PowerShell scripts for daily workflow automation and task management.

## 📜 Available Scripts

- **`auto-push.ps1`** — Automates Git workflow (`git add`, `git commit`, `git push`).

> [!WARNING]  
> **Prerequisites:** The Git repository must be initialized (`git init`) and have at least **one initial commit** made manually before running the script.
